# cron/output — 定时任务输出目录

## 模块说明

本目录存放所有 Cron 定时任务执行后自动生成的输出产物，包括各类巡检报告、数据聚合结果、智能简报等。作为 cron 模块的持久化输出层，确保每次任务执行的结果可追溯、可查阅。

## 核心功能

- **定时报告存储**：自动汇聚并保存周期任务（如每日巡检、周报）的输出文件
- **归档与追溯**：保留历史执行结果，支持回溯任意时间点的任务输出
- **内容聚合**：将多个数据源（日志、监控、知识库）的增量信息合并为统一报告
- **智能摘要生成**：通过 LLM 与规则引擎将原始数据转化为结构性报告

## 使用方式

Cron 调度器自动写入本目录，无需手动干预。历史文件以日期命名（如 `YYYYMMDD_*`），可通过文件名时间戳定位。

```bash
# 查看最近输出的报告
ls -lt cron/output/ | head -5

# 查看指定日期的报告
cat cron/output/20260706_shenjiying88_intelligence_report.md
```

## 目录结构

```
cron/output/
├── README.md                                                  # 本文件
├── 20260706_shenjiying88_intelligence_report.md               # 智能报告示例
└── ...                                                         # 更多报告文件
```

> **注意**：本目录内容由定时任务自动管理，不推荐手动创建或修改文件。
