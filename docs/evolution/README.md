# 🧬 演进文档目录

## 用途说明

本目录记录 M5 平台的自进化评分与演进指标，用于量化系统在知识图谱增长、反模式修复、专家洞察积累及 Pulse 巡检通过率等维度的持续改进情况。演进数据帮助团队直观了解平台从 V6 到 V21 的开发成熟度提升趋势，是驱动开发规范迭代的重要度量依据。

## 内容说明

- **`evolution-2026-06-28-10.md`** — V6.3 版本的自进化指数快照（Evolution Index = 173.10），基于知识图谱节点数（117）、反模式数（40）、课程数（2）、专家洞察数（3）及 Pulse 夜间巡检通过率（100%）计算得出。
- **`score-2026-07-20.md`** — V21 每日健康评分（S 级 100/100），从测试通过分（40%）、树哥合规分（20%）、TSC 稳定分（20%）和闭环率分（20%）四个维度加权计算，附当日 76 次 commit 的基础数据说明。

## 如何使用

1. **演进趋势追踪**：翻阅按时间排序的演进记录文件，可追踪 Evolution Index 与健康评分的长期趋势，判断平台成熟度是否持续改善。
2. **评分解读**：每个演进记录文件均包含详细的计算公式与权重分配，读者可按该标准自行验证得分是否准确。
3. **新增记录**：新的演进记录应遵循已有模板格式，包含评分时间、计算维度与权重、原始数据来源及最终得分说明。建议在每次版本迭代结束时生成一次演进快照。
4. **关联阅读**：演进评分的变化通常与 `docs/monitoring/` 的日报指标（如 Pulse 通过率）、`docs/knowledge/` 的知识图谱更新数存在联动关系，建议交叉查阅以获取全局视角。
