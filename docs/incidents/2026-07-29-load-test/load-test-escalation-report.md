## 🏆 关键发现

### 1️⃣ API 极限 ≈ 1000 VU
- 1000 VU / 826 RPS / P95 164ms / P99 1.1s
- 超过此值后 P99 显著上升 (1.1s)，但仍 < 2s 阈值
- 单机本地 API 极限 ≈ 800-1000 RPS 持续稳定

### 2️⃣ 健康/下单/校验 端点隔离分析
| 端点   | 50 VU  | 200 VU  | 500 VU  | 1000 VU | 备注 |
|:------|------:|------:|------:|------:|:----|
| health/ping P95 | 11ms | 408ms | 95ms | 274ms | 偶发抖动 |
| cashier/orders P95 | 10ms | 51ms | 25ms | 126ms | 稳定 |
| minor-protection/verify P95 | 10ms | 228ms | 72ms | 176ms | 需 token |

### 3️⃣ 阈值达标矩阵
| 阈值项          | 目标    | 50 VU | 200 VU | 500 VU | 1000 VU |
|:----------------|------:|:----:|:----:|:----:|:----:|
