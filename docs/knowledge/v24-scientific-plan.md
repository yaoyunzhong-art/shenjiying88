## 五、树哥运行模式调整

### V23 模式（旧）
```
保底续产（30分钟一次）→ 70% 产出
树哥三线全开（A/B/C 全模块轮查）
目标：15+ Service 测试 / 25+ E2E 测试 / 1 README
```

### V24 模式（新）
```
需求驱动（按 Phase 计划指定任务 → 完成即停）
树哥按需分派（不是三线全开，是指定1-3个任务并行）
保底续产保留但降频（每 2h 一次检查工作区 → 有则commit，无则跳过）
目标：完成交付物 → 验证通过 → 闭环
```
