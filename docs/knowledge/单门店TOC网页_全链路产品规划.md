## 一、核心定位

**一句话定位**：为单门店打造的「本地经营驾驶舱 × 消费者超级入口 × AI赋能中枢」三位一体TOC网页。

该网页不是简单的"门店信息展示页"，而是：
- 🏪 **经营侧**：门店的线上收银台、预约中心、流量入口
- 🧑‍💻 **消费者侧**：从发现门店→预约下单→到店核销→离店复购的完整闭环
- 🤖 **AI侧**：7×24小时导购、个性化推荐、经营数据参谋

**目标**：到店转化率提升25%+，预约核销率>85%，客户复购率>40%

## 四、技术架构约束 (宪法硬要求)

### 4.1 性能基准

| 指标 | 目标 | 测量方式 |
|------|------|----------|
| 首页LCP | ≤2s | Lighthouse / Web Vitals |
| 预约流程步骤 | ≤3步 | 用户行为埋点 |
| 支付完成时间 | ≤30s (从点击支付到成功) | API调用链追踪 |
| 移动端适配率 | 100% | BrowserStack 多设备测试 |
| API响应P99 | ≤500ms (读) / ≤2s (写) | Prometheus |
| 页面可用率 | 99.9% | Uptime监控 |

### 4.2 安全合规

| 约束 | 来源 | 实现 |
|------|------|------|
| TLS 1.3 + AES-256 | §17 安全基线 | Nginx/CDN强制HTTPS |
| 未成年人保护 (月消费≤2000, 冷静期) | §22 合规消费保护 | 下单时年龄校验+限额 |
| 盲盒概率公示 (每抽实时显示) | §22 消费者保护 | 概率引擎+公示页面 |
| 隐私政策 + 用户协议 | §22 法律合规 | 页面底部链接 |
| 数据不出境 (中国本地存储) | 监管要求 | 阿里云国内节点 |
| API 防刷 (Rate Limiting) | 安全审计A+ | Redis限流+Guard |

### 4.3 社媒合规边界

- 分享内容自动过审 (敏感词过滤, 违规内容不展示)
- 达人探店需标注"广告"标识 (广告法合规)
- UGC内容AI审核+人工复审 (涉黄涉暴涉政自动拦截)
- 直播内容录制备份 (合规留存30天)
