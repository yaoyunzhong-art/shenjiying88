## 1. 目标

### 1.1 业务目标
为POS系统提供统一商品分类管理，支持按品类检索、分类统计、CRUD能力，作为商品/库存管理的核心基础数据。

### 1.2 产品目标
- 预置10个常见商品分类(餐饮/服装/数码/日用品等)
- 支持分类的完整CRUD
- 支持按名称精确查询(含URL编码)
- 支持按关键词模糊搜索
- 为下游商品模块提供分类数据源

### 1.3 成功指标
| 指标 | 目标值 | 测量方式 |
|:----|:------|:---------|
| 分类列表查询 | ≤1秒 | APM |
| 分类创建响应 | ≤500ms | APM |
| 模糊搜索准确率 | 100%(匹配关键字) | 集成测试 |
| 分类去重 | 名称唯一，不重复创建 | 单元测试 |
| 错误码覆盖率 | 3种错误(不存在/重复/无效名)全覆盖 | 测试覆盖 |

## 5. 数据约束

### 5.1 数据库约束

| 约束 | 说明 | 理由 |
|:-----|:-----|:-----|
| 名称唯一 | Category.name 不区分大小写唯一 | 防重复 |
| 名称非空 | 名称不可为空/纯空白 | 数据规范 |
| 名称URL解码 | 输入名称自动URL解码(前端可能编码) | 接口兼容 |
| 搜索大小写不敏感 | 搜索时将名称/描述转为小写 | 用户友好 |
| 查询副本 | 所有查询返回副本，防止外部修改 | 数据安全 |
| 删除后不可恢复 | 删除非物理，仅从内存中移除 | 当前版本 |

### 5.2 关键数据实体

```typescript
interface Category {
  name: string;                          // 分类名称(唯一)
  description: string;                   // 分类描述
  productCount: number;                  // 商品计数
}

enum CategoryErrorCode {
  NOT_FOUND = 'CATEGORY_NOT_FOUND',
  DUPLICATE = 'CATEGORY_DUPLICATE',
  INVALID_NAME = 'CATEGORY_INVALID_NAME',
}
```
