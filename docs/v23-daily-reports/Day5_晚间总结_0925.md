## 技术要点

### return-wrapper 模式

```tsx
// ✅ 正确模式（v2 脚本生成）
return (
  <AdminPermissionGate
    requiredPermission={permissionGate.requiredPermission}
    title={permissionGate.title}
    description={permissionGate.description}
  >
    <PageContent />
  </AdminPermissionGate>
)

// ❌ 错误模式（v1 尝试）
<AdminPermissionGate>...</AdminPermissionGate>
return ( <PageContent /> )
// → TSC error: JSX 不能作为独立语句出现在函数体中
```

### 批量注入脚本

`scripts/p38-wrap-jsx.mjs` — 自动检测含 `permissionGate` config 但缺 `<AdminPermissionGate>` JSX 的页面，在 `return (...)` 内部包裹权限门。

Usage: `node scripts/p38-wrap-jsx.mjs apps/admin-web`
