# 📊 监控文档目录

## 用途说明

本目录存放 M5 平台的日常监控与运维报告，用于追踪系统健康状态、RFC 投票进展、Pulse 闭环执行情况以及夜间自动化巡检结果。监控体系覆盖了关键指标、合规审计、投票倒计时等多个维度，是团队及时发现异常和保障系统稳定运行的第一道防线。

## 内容说明

目录内包含以下文件与子目录：

- **`2026-06-26.md`**、**`2026-06-28.md`** — 日常监控日报，记录当日 RFC 状态总览、关键指标（commit 数、投票进度、阻塞项）及 Pulse 闭环检查结果。
- **`vote-countdown.log`** — RFC 投票倒计时日志，跟踪各 RFC 的截止时间与剩余时长，用于提醒 Approver 及时投票。
- **`nightly/`** — 夜间巡检子目录，存放每日凌晨自动运行的巡检报告（含 `launchd-errors.log`、`launchd.log` 等），用于排查定时任务与后台服务的异常。

## 如何使用

1. **查阅日报**：按日期文件名（如 `2026-06-26.md`）直接打开，查看当日系统健康评分、RFC 状态与 Pulse 闭环率。
2. **投票监控**：`vote-countdown.log` 由监控脚本自动追加，开发人员应定期检查以跟踪 RFC 截止时间，避免投票逾期。
3. **夜间巡检**：`nightly/` 下的日志需在每日晨会前查阅，若发现 `launchd-errors.log` 有新增报错，应立即排查对应定时任务。
4. **新增日报**：新建文件请按 `YYYY-MM-DD.md` 命名格式，并遵循已有模板中的关键指标表头与 RFC 状态表结构。
