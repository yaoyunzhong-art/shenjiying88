# docs/standup — 站会记录目录

## 模块说明

本目录归档 Shenjiying88 团队每日站会（Standup）的会议记录，包括常规日常站会与审批者（Approver）专项站会的纪要文档。所有站会记录以 Markdown 格式保存，按日期命名，方便团队成员后续查阅与追溯。

## 核心功能

- **站会纪要归档**：保存每一次日常站会的讨论记录、进度同步和待办事项
- **审批者站会记录**：独立归档 Approver 站会的决策与关键评审结论
- **时间线追溯**：通过文件名日期可快速定位特定时间点的团队状态
- **知识沉淀**：将口头同步转化为书面文档，形成团队记忆

## 使用方式

站会记录由自动化流程或记录员在站会后写入。团队成员可通过以下方式查阅：

```bash
# 查看所有站会记录
ls -la docs/standup/

# 查看某次站会详情
cat docs/standup/standup-2026-07-02.md

# 搜索特定关键词
grep -r "关键议题" docs/standup/
```
