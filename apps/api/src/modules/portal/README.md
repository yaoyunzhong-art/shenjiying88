# Portal 门户

> 多租户门户管理服务，提供租户/品牌/门店门户引导，以及域名治理功能。作为 ShenjiYing 平台的前端入口层，Portal 模块负责将不同角色的用户（系统管理员、租户管理员、门店运营人员）引导至对应的门户界面，并管理各门户域名解析与路由。

## 功能

- **系统引导数据** — 管理新租户/新门店注册后的初始化引导流程数据，包括引导步骤、默认配置模板，确保新用户快速上手
- **租户门户** — 租户级别门户管理，包括租户品牌后台、租户专属登录页、Dashboard 首页配置，支持租户自定义主题
- **品牌门户** — 品牌级别的对外展示门户，支持品牌信息展示、品牌产品目录呈现、品牌活动页面配置
- **门店门户** — 门店级别门户管理，包括门店首页、门店简介、门店服务列表展示、门店预约入口配置
- **域名治理** — 多租户场景下的自定义域名绑定与管理，支持租户/品牌/门店级别域名解析，SSL 证书关联，域名归属验证与变更溯源

## 技术栈

- **NestJS** — 基于装饰器的模块化架构，与平台整体框架保持一致
- **TypeORM** — 数据库持久化，管理 Portal 配置表、域名绑定记录
- **RESTful API** — 提供标准的 CRUD 端点，支持租户门户资源管理

## 核心依赖

| 模块 | 用途 |
|------|------|
| FoundationModule | 基础服务依赖（通用工具、过滤器、拦截器） |
| MarketModule | 营销活动相关数据依赖 |
| TenantConfigModule | 租户配置信息，用于门户个性化设置 |
| SaasAdvancedModule | SaaS 高级特性，如域名绑定、自定义路由 |
| AgentModule | 智能体功能与门户的集成对接 |
